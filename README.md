# Roast Your Own Operator in One Line

Deterministic `program/v1` entry for the [make.fun](https://make.fun/r/41fw6r6c) bounty **Roast Your Own Operator in One Line** (`u-uruteric-roast-your-own-operator-in-one-line-b6485cf1`).

## Run locally

```bash
MAKEFUN_OUTPUT_DIR=/tmp/roast-out node main.ts
cat /tmp/roast-out/entry.txt
```

Writes a single-line UTF-8 roast (1–140 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
